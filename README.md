## Описание

Данный репозиторий посвящён работе с билдом **'xrCore Build' 2203, Apr 13 2005** - одним из ранних прототипов движка X-Ray, показанного в трейлере *"The Toughest Enemy"*.

Билд демонстрирует:
- Упор на **ночные сцены и закрытые пространства**
- Продвинутое для своего времени **динамическое освещение**
- **Реалистичные тени** от всех объектов

---

## Цели проекта

Основная задача - **адаптировать старый билд под современные системы и инструменты**, сохранив его оригинальную атмосферу.

### Ключевые цели:
- Сборка проекта в **Visual Studio 2022**
- Поддержка **высоких разрешений**
- Замена **DirectInput 7 → DirectInput 8**
- Исправление некоторых старых багов и нестабильностей
