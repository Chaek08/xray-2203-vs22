# Build 2203 VS22 Port (DX9, 2005 Build)

> Восстановление и модернизация раннего билда движка X-Ray (Build 2203) под современные инструменты разработки.

## Описание

Данный репозиторий посвящён работе с билдом **'xrCore Build' 2203, Apr 13 2005** - одним из ранних прототипов движка X-Ray, показанного в трейлере *[The Toughest Enemy](https://youtu.be/flsREXxNIpQ)*.

Билд демонстрирует:
- Упор на **ночные сцены и закрытые пространства**
- Продвинутое для своего времени **динамическое освещение**
- **Реалистичные тени** от всех объектов
